# GlassShot

GlassShot is a high-performance, lightweight CleanShot X clone for Windows built with C# and WPF (.NET 8). It prioritizes zero-latency UX, pixel-perfect visuals, and robust system-level hooks.

## Getting Started
1. Ensure you have the .NET 8 SDK installed.
2. Open the directory in your terminal.
3. Run `dotnet run` to build and launch the application.
4. Press `ctrl + shift + c` to activate the global capture overlay.
